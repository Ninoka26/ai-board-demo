# ИИ-доска — исходный код прототипа

Версия 1.3. Основные файлы: `board.html` (интерфейс), `server.py` (локальный Python-сервер).

**Важно:** этот репозиторий содержит исходный код, а не опубликованный веб-сервис. Сейчас сервер слушает только `127.0.0.1:8765`, распознавание речи требует `faster-whisper` и `ffmpeg`, а GigaChat использует защищённый ключ Windows DPAPI, который не публикуется.

Не загружайте в репозиторий ключи API, личные заметки, JSON-резервные копии и файлы из `%LOCALAPPDATA%/AI_Board`.

Для тестирования с другими людьми требуется отдельный сервер HTTPS, авторизация, разделение пользовательских данных, лимиты запросов и безопасное управление ключом ИИ. До этого момента не выставляйте `server.py` напрямую в интернет.

Семейный проект «Пока я помню» не связан с этим репозиторием.
